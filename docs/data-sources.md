# 資料來源

## 主要資料來源

### 165反詐騙諮詢專線_遭停止解析涉詐網站

- 來源：政府資料開放平臺
- URL：https://data.gov.tw/dataset/176455
- 用途：整理涉詐網站、網域與相關欄位。
- 注意：CSV 實際下載網址可能會因政府資料平臺更新而改變，因此本專案使用 `ANTI_SCAM_CSV_URL` 作為環境變數。

### 165 全民防騙網

- 來源：內政部警政署
- URL：https://165.npa.gov.tw/
- 用途：作為官方防詐資訊入口。

### 165 打詐儀錶板

- 來源：內政部警政署
- URL：https://165dashboard.tw/
- 用途：參考最新詐騙案例、常見手法與趨勢。

## 資料使用原則

- 優先使用官方公開資料。
- 不收集私人對話。
- 不收集電話錄音。
- 不收集金融帳號密碼或驗證碼。
- 若新增資料來源，必須在本檔案記錄 URL、授權、用途與風險。
